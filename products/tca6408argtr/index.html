Product Introduction

The TCA6408A is a 16-pin device that provides 8-bit general-purpose parallel I/O expansion for the two-wire bidirectional I2C bus (or SMBus) protocol. During device operation, both the I2C bus side (VCCI) and the P-port side (VCCP) can be powered by supplies ranging from 1.65V to 5.5V. This allows the TCA6408A to interface with next-generation microprocessors and microcontrollers on the SDA/SCL side, where supply voltages are being reduced to save power. Unlike the trend toward lower supply voltages for microprocessors and microcontrollers, some PCB components (such as LEDs) still require a 5V supply.

The device supports clock frequencies of 100kHz (standard mode) and 400kHz (fast mode). When additional I/O is needed for devices such as switches, sensors, buttons, LEDs, and fans, I/O expanders like the TCA6408A provide a simple solution.

Features

  • I2C-to-parallel port expander
  • Operating supply voltage range: 1.65V to 5.5V
  • Supports bidirectional voltage-level translation and GPIO expansion between 1.8V, 2.5V, 3.3V, and 5V I2C bus and P-port
  • 1μA low standby current consumption
  • 5V-tolerant I/O ports
  • 400kHz fast-mode I2C bus
  • Hardware address pins allowing two TCA6408A devices on the same I2C/SMBus
  • Active-low reset (RESET) input
  • Open-drain active-low interrupt (INT) output
  • Input and output configuration registers
  • Polarity inversion register
  • Internal power-on reset
  • All channels configured as inputs at power-up
  • Glitch-free power-up
  • Noise filters on SCL and SDA inputs
  • Latched outputs with maximum high-current drive capability for direct LED driving
  • Latch-up performance exceeding 100mA per JESD78 Class II
  • Schmitt-trigger inputs on SCL and SDA for slow input transitions and improved switching noise immunity
  • ESD protection exceeding JESD22
  • 2000V Human Body Model (A114-A)
  • 1000V Charged Device Model (C101)

Applications

  • Servers
  • Routers (telecom switching equipment)
  • Personal computers
  • Personal electronics (gaming consoles)
  • Industrial automation
  • Products with GPIO-constrained processors
