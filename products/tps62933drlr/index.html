Product Introduction

The TPS6293x is an easy-to-use, high-efficiency synchronous buck converter featuring a wide input voltage range of 3.8V to 30V, supporting continuous output currents up to 2A (TPS62932) and 3A (TPS62933 and TPS62933x), with an output voltage range of 0.8V to 22V.

The device employs fixed-frequency peak current control mode, enabling fast transient response and excellent line and load regulation. The internal loop compensation is optimized, eliminating the need for external compensation components.

The TPS62932, TPS62933, and TPS62933P operate in pulse frequency modulation mode for high light-load efficiency. The TPS62933F operates in forced continuous current modulation mode to maintain low output ripple under all load conditions. The TPS62933O operates in Out-of-Audio mode to avoid audible noise.

The ULQ (Ultra-Low Quiescent) feature helps extend battery life. The switching frequency can be set by configuring the RT pin over a range of 200kHz to 2.2MHz, optimizing system efficiency, solution size, and bandwidth. The soft-start time for the TPS62932, TPS62933, and TPS62933F can be adjusted via an external capacitor on the SS pin. The TPS62932, TPS62933, TPS62933P, and TPS62933O feature spread-spectrum frequency modulation to help reduce EMI noise.

The TPS6293x is available in a compact SOT583 (1.6mm×2.1mm) package with 0.5mm pin pitch, featuring an optimized pin arrangement to simplify PCB layout and provide good EMI performance.

Features

  • Versatile configuration for a wide range of applications
  • 3.8V to 30V input voltage range
  • 0.8V to 22V output voltage range
  • Ultra-low quiescent current: 12μA (TPS62932, TPS62933, and TPS62933P)
  • Integrated 76mΩ and 32mΩ MOSFETs
  • 0.8V ±1% reference voltage (25°C) with up to 98% duty cycle operation
  • Precision EN threshold
  • 2A (TPS62932) and 3A (TPS62933 and TPS62933x) continuous output current
  • −40°C to 150°C operating junction temperature range
  • Wide selection of pin-compatible options
  • SS pin on TPS62932, TPS62933, and TPS62933F for adjustable soft-start time
  • PG pin on TPS62933P and TPS62933O as power-good indicator
  • High light-load efficiency via PFM for TPS62932, TPS62933, and TPS62933P
  • Forced continuous conduction mode (FCCM) for TPS62933F
  • Out-of-Audio (OOA) function for TPS62933O
  • Compact solution size and ease of use
  • Peak current mode with internal compensation
  • Selectable frequency from 200kHz to 2.2MHz
  • Low EMI with spread spectrum (TPS62932, TPS62933, TPS62933P, and TPS62933O)
  • Pre-biased output startup support
  • Cycle-by-cycle overcurrent limiting for high-side and low-side MOSFETs
  • Non-latching OTP, OCP, OVP, UVP, and UVLO protection
  • 1.6mm × 2.1mm SOT583 package
