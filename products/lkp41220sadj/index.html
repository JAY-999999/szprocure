Product Introduction

LKP41220S is a series of low-noise LDO regulators. The device integrates a voltage reference, error amplifier, power transistor, over-temperature protection, and over-current protection. It features a wide input voltage range, high output current capability, and low output noise, along with an enable function for controlling the operating state of the circuit.

Features

  • Input voltage range: 2.5V~20V
  • Adjustable output voltage: 1.21V~20V
  • Fixed output voltage: 1.8V, 3.3V
  • Maximum output current: 1.5A
  • Low quiescent current: 1mA
  • Low dropout: 340mV@1.5A
  • Low noise: 40μVRMS (10Hz~100kHz)
  • Shutdown quiescent current: ≤1μA
  • Package: SOP8 (4.90mm×6.00mm×1.55mm)
  • Plastic encapsulation

Applications

  • Post-regulator for 3.3V to 2.5V logic supply switching power supplies
