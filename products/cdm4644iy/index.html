Product Introduction

The CDM4644 is a standalone quad-channel 4A step-down DC/DC micro-module power supply. It supports multiple outputs or parallel array outputs, with a maximum output current of 16A.

The module integrates a switching controller, power FETs, inductors, high-precision upper voltage divider resistors (0.1%), and supporting components. Only a small number of external filter/hold capacitors and resistors are required to form a complete step-down quad-output DC/DC voltage regulator.

The module input voltage range is 4V to 14V, and the output voltage can be set between 0.6V and 5.5V via an external sense resistor.

The module supports external frequency synchronization, continuous/discontinuous mode, and output voltage tracking sequencing operation. It features built-in temperature monitoring, over-temperature, over-voltage, and over-current protection.

Features

  • Quad-channel 4A step-down micro module
  • Wide input voltage range: 4V～14V, external bias supply down to 2.4V
  • Output voltage range: 0.6V～5.5V
  • 4A rated output per channel, 5A peak
  • Up to 5.5W power dissipation without heatsink (TA = 60°C, 200LFM)
  • ±1.5% total output voltage regulation
  • Current mode control for fast transient response
  • Parallel multi-channel operation for higher output current
  • Output voltage tracking
  • Internal/external temperature sensing with synchronous diode output
  • OVP, OCP, and OTP

Applications

  • Multi-rail point-of-load regulation for FPGA, DSP, and ASIC applications
