Product Introduction

The TCAN1044-Q1 is a high-speed Controller Area Network (CAN) transceiver that meets the physical layer requirements of the ISO 11898-2:2016 high-speed CAN specification. The TCAN1044-Q1 transceiver supports both traditional CAN and CAN FD networks (with data rates up to 8 megabits per second (Mbps)). The TCAN1044-Q1 includes an internal logic level conversion function via the V₁₀ terminal, allowing the transceiver I/O to be directly connected to 1.8V, 2.5V, 3.3V, or 5V logic I/O. This transceiver supports a low-power standby mode and can be awakened via CAN in accordance with the wake-up mode (WUP) defined in ISO 11898-2:2016. Additionally, the TCAN1044-Q1 transceiver also includes protection and diagnostic functions, supporting thermal shutdown (TSD), TXD dominant timeout (DTO), power supply undervoltage detection, and bus fault protection up to ±58V.
