Product Introduction

CD51200 is a sink/source DDR termination regulator designed specifically for space-constrained systems requiring low input voltage, low cost, and low noise.

CD51200 maintains fast transient response with only 20μF ultra-low output capacitance. CD51200 supports remote sense and meets all power requirements for DDR, DDR2, DDR3, DDR3L, Low Power DDR3, and DDR4 VTT bus termination.

In addition, CD51200 provides an open-drain PGOOD signal for output regulation monitoring and an EN signal to discharge VTT for DDR applications during S3 (Suspend-to-RAM).

Features

  • Input voltage: supports 2.5V and 3.3V supply rails
  • VLDOIN voltage range: 1.1V to 3.5V
  • Sink and source termination regulator with dropout compensation
  • Requires ultra-small output capacitance of 20μF (typically 3×10μF MLCC) for memory termination applications (DDR)
  • PGOOD for output regulation monitoring
  • EN input
  • REFIN input allows flexible input tracking remote sense (VOSNS) directly or via resistor divider
  • ±10mA buffered reference (REFOUT)
  • Integrated soft-start, undervoltage protection, and overcurrent protection
  • Thermal shutdown
  • Supports DDR, DDR2, DDR3, DDR3L, Low Power DDR3, and DDR4 VTT applications
  • Package: VSON10 (3mm×3mm)

Applications

  • - Memory termination regulator for DDR, DDR2, DDR3, DDR3L, Low Power DDR3, and DDR4 - Laptops, desktops, and servers - Telecom and data communications - Base stations - LCD and plasma TVs - Copiers and printers - Set-top boxes
