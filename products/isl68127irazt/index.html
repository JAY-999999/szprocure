Product Introduction

The ISL68127 is a digital dual-output, flexible multiphase (X+Y ≤ 7) PWM controller supporting the latest PMBus V1.3 specification. The device is configurable to support any distribution of up to seven phases across two outputs (X+Y), such as 6+1, 5+2, 4+2, 3+3, 3+2, and even single-output operation as a 7+0 configuration. The ISL68127 employs Renesas' proprietary linear synthesized digital current modulation scheme to deliver an industry-best combination of transient response and ease of tuning, while addressing the challenges of modern multiphase designs. Users can configure the device and monitor telemetry data through the intuitive Renesas PowerNavigator GUI. The ISL68127 supports on-chip non-volatile memory for storing multiple user-selectable configuration settings that can be pin-strapped, providing system designers with greater power density to configure and deploy multiple configurations. Automatic phase add/drop enables maximum efficiency across all load ranges. Automatic phase add/drop thresholds are user-programmable via PowerNavigator. The ISL68127 supports a comprehensive fault management system for high-reliability system design. From multilevel overcurrent protection schemes to configurable power good and output overvoltage/undervoltage fault thresholds and temperature monitoring, virtually any requirement can be met. With minimal external components, easy configuration, robust fault management, and high-precision regulation, achieving a high-performance multiphase voltage regulator has never been easier.

Features

  • Advanced linear digital modulation scheme
  • Zero-latency synthetic current control for excellent high-frequency current balancing
  • Double-edge modulation for fastest transient response
  • Automatic phase add/drop for superior load versus efficiency profile
  • PMBus V1.3 support
  • Telemetry: VIN, VOUT, IOUT, input/output power, temperature, and various fault status registers
  • Bus interface up to 1MHz
  • Flexible phase configuration
  • Supports 7+0, 6+1, 5+2, and 4+3 phase operation
  • Also supports operation with fewer than seven phases between two outputs
  • Diode braking to reduce overshoot
  • Differential remote voltage sensing for ±0.5% closed-loop system accuracy across load, line, and temperature range
  • High-accuracy current sensing for superior load line regulation and precise overcurrent protection
  • Supports ISL99227 60A smart power stage
  • Supports DCR sensing with integrated temperature compensation
  • Comprehensive fault management for high-reliability systems
  • Cycle-by-cycle phase current limiting
  • Total output current protection
  • Output and input OVP/UVP
  • Voltage sense open-circuit detection
  • Black box function for fault logging
  • Intuitive configuration using PowerNavigator
  • Non-volatile memory stores up to eight configurations
  • Lead-free (RoHS compliant)

Applications

  • - Networking equipment - Telecom and data communications equipment - Server and storage equipment - Point-of-load power supplies (memory, DSP, ASIC, FPGA)
