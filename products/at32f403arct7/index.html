Product Introduction

ARTERY AT32F403ARCT7 - ARM Cortex-M4F - 240 MHz - 256 KB Flash - 51 I/O

Features

  • ARM 32-bit Cortex-M4F CPU with FPU
  • Up to 240 MHz operating frequency with MPU, single-cycle multiplication and hardware division
  • Built-in FPU with DSP instruction set
  • 256 KB to 1024 KB internal Flash program/data memory
  • sLib: designates a specified main memory region as a secure execute-only code library — code in this region can be called but not read
  • SPIM interface: additional external SPI Flash program/data memory interface up to 16 MB
  • Up to 96 + 128 KB SRAM
  • XMC with 2 chip selects, supporting NOR/PSRAM and NAND memory with multiplexed signals
  • Parallel LCD interface, compatible with 8080/6800 modes
  • 2.6 to 3.6 V supply and I/O pins
  • POR/PDR, PVD
  • 4 to 25 MHz crystal oscillator
  • Built-in factory-trimmed 48 MHz RC oscillator (1% accuracy at 25°C, 2.5% accuracy over -40°C to +105°C) with ACC
  • Built-in calibrated 40 kHz RC oscillator
  • 32 kHz crystal oscillator with calibration
  • Sleep, stop and standby modes
  • VBAT supply for RTC and 42 × 16-bit backup registers
  • 3 × 12-bit ADCs, 0.5 μs conversion time (up to 16 input channels)
  • Conversion range: 0 to 3.6 V
  • Triple sample-and-hold
  • Temperature sensor
  • 2 × 12-bit DACs
  • 14-channel DMA controller
  • Supported peripherals: timers, ADC, DAC, SDIO, I2S, SPI, I2C and USART
  • SWD and JTAG interfaces
  • Cortex-M4F embedded trace module (ETM)
  • 37/51/80 multifunctional bidirectional I/O pins; all I/Os mappable to 16 external interrupts; almost all I/Os 5V-tolerant
  • All I/Os are fast I/Os with register access up to fAHB
  • Up to 8 × 16-bit timers + 2 × 32-bit timers, each with up to 4 channels for input capture/output compare/PWM or pulse counting, and incremental encoder input
  • Up to 2 × 16-bit advanced PWM timers with dead-time control and emergency brake for motor control
  • 2 watchdog timers (independent and windowed)
  • SysTick timer: 24-bit down counter
  • 2 × 16-bit basic timers for DAC driving
  • Up to 3 × I2C interfaces (SMBus/PMBus support)
  • Up to 8 × USART interfaces (ISO7816, LIN, IrDA and modem control support)
  • Up to 4 × SPI interfaces (50 Mbit/s), all 4 multiplexable as I2S; I2S2/I2S3 support full-duplex
  • Up to 2 × CAN interfaces (2.0B Active)
  • USB 2.0 full-speed device interface, crystal-less support
  • Up to 2 × SDIO interfaces
