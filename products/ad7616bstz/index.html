Product Introduction

The AD7616 is a 16-bit DAS that supports dual simultaneous sampling of 16 channels. Operating from a 5 V single supply, it can handle ±10 V, ±5 V, and ±2.5 V true bipolar input signals, with each channel pair sampling at throughput rates up to 1 MSPS and 90.5 dB SNR. Higher SNR performance is achievable using the on-chip oversampling mode (SNR of 92 dB at OSR of 2).

The input clamp protection circuit can withstand voltages up to ±21 V. The AD7616 presents an analog input impedance of 1 MΩ regardless of the sampling frequency. Its single-supply operation, on-chip filtering, and high input impedance eliminate the need for drive op-amps and external bipolar supplies.

The device integrates analog input clamp protection, a dual 16-bit charge redistribution SAR ADC, a flexible digital filter, a 2.5 V voltage reference and reference buffer, and high-speed serial and parallel interfaces.

The AD7616 is compatible with SPI/QSPI/DSP/MICROWIRE.

  • Flexible parallel/serial interface
  • SPI/QSPI/MICROWIRE/DSP compatible

  • THD: −103 dB

  • 8 kV ESD rating on analog input channels
  • On-chip self-test function
  • 80-lead LQFP package
