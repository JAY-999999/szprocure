Product Introduction

The SimpleLink™ CC2642R device is a 2.4GHz wireless MCU supporting Bluetooth® 5.2 Low Energy and proprietary 2.4GHz applications. The device is optimized for low-power wireless communication and advanced sensing in building security systems, HVAC, asset tracking, medical, wired networking, portable electronics, home theater and entertainment, connected peripherals markets, and applications requiring industrial-grade performance.

Features

  • High-performance 48MHz Arm® Cortex®-M4F processor
  • EEMBC CoreMark® score: 148
  • 352KB in-system programmable flash
  • 256KB ROM for protocol and library functions
  • 8KB cache SRAM (also available as general-purpose RAM)
  • 80KB ultra-low leakage SRAM; SRAM protected by parity for highly reliable operation
  • 2-pin cJTAG and JTAG debug
  • Over-the-Air (OTA) update support
  • Ultra-low-power sensor controller with 4KB SRAM
  • Samples, stores, and processes sensor data
  • Operates independently of the system CPU
  • Fast wakeup into low-power operation
  • TI-RTOS, drivers, bootloader, and Low Power Bluetooth® 5.2 controller embedded in ROM for optimized application size
  • RoHS-compliant package
  • 7mm × 7mm RGZ VQFN48 (31 GPIOs)
  • Peripherals
  • Digital peripherals connectable to any GPIO
  • Four 32-bit or eight 16-bit general-purpose timers
  • 12-bit ADC, 200ksps, 8-channel
  • 2 comparators with internal reference DAC (1 continuous-time comparator, 1 ultra-low-power comparator)
  • Programmable current source
  • 2 asynchronous transceivers (UART)
  • 2 synchronous serial interfaces (SSI) (SPI, MICROWIRE, and TI)
  • I2C and I2S
  • Real-Time Clock (RTC)
  • AES 128-bit and 256-bit crypto accelerator
  • ECC and RSA public key hardware accelerator
  • SHA2 accelerator (full suite up to SHA-512)
  • True Random Number Generator (TRNG)
  • Capacitive sensing, up to 8 channels
  • Integrated temperature and battery monitor
  • External system
  • On-chip buck DC/DC converter
  • Active mode RX: 6.9 mA
  • Active mode TX (0dBm): 7.3mA
  • Active mode TX (5dBm): 9.6 mA
  • Active mode MCU 48MHz (CoreMark): 3.4mA (71μA/MHz)
  • Sensor controller (low-power mode, 2MHz, running infinite loop): 30.1 μA
  • Sensor controller, active mode, 24MHz, running infinite loop: 808 μA
  • Standby current: 0.94 μA (RTC running, 80KB RAM and CPU retained)
  • Shutdown current: 150nA (wakeup on external event)
  • 2.4GHz RF transceiver, compatible with Bluetooth Low Energy 5.2 and earlier LE specifications
  • 3-wire, 2-wire, 1-wire PTA coexistence
  • Excellent receiver sensitivity: -105 dBm at Bluetooth 125kbps (LE Coded PHY), -97dBm at 1Mbps (PHY)
  • Output power up to +5dBm with temperature compensation
  • Suitable for systems complying with global RF regulations
  • EN 300 328 (Europe)
  • EN 300 440 Category 2
  • FCC CFR47 Part 15
  • ARIB STD-T66 (Japan)
  • CC26x2R LaunchPad™ development kit
  • SimpleLink™ CC13x2 and CC26x2 Software Development Kit (SDK)
  • SmartRF™ Studio for simple radio configuration
  • Sensor Controller Studio for building low-power sensing applications
