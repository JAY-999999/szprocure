Product Introduction

The DP83822 is an ultra-robust, low-power, single-port 10/100Mbps Ethernet PHY, making it an ideal choice for harsh industrial environments. It provides all the physical layer functions required to transmit and receive data over standard twisted-pair cables or connect to an external fiber optic transceiver. Additionally, the DP83822 can be flexibly connected to the MAC via standard MII, RMII, or RGMII interfaces. For ease of use, the DP83822 offers integrated cable diagnostic tools, built-in self-test, and loopback functions. It can support multiple industrial fieldbuses with its fast link detection and auto-MDIX function in forced mode. The DP83822 provides an innovative and reliable solution to reduce power consumption through EEE, WoL, and other programmable power-saving modes. The DP83822 is a feature-rich, pin-to-pin upgrade option for the TLK105, TLK106, TLK105L, and TLK106L 10/100 Mbps Ethernet PHYs.

Features

  • Ultra-robust 10/100Mbps PHY
  • IEC 6100-4-2 ESD: +/-8KV contact discharge
  • IEC 6100-4-4 EFT: Class A at 4KV
  • CISPR 22 conducted emissions: Class B
  • CISPR 22 radiated emissions: Class B
  • Operating temperature: -40°C to 125°C
  • MAC interface: RGMII/RMII/MII compliant with IEEE 802.3u: 100BASE-FX, 100BASE-TX, and 10BASE-Te
  • Flexible power supply options
  • Low-power single supply options
  • 1.8V AVD < 120mW
  • 3.3V AVD < 220mW
  • Available I/O voltage: 3.3V/2.5V/1.8V
  • Power-saving features
  • Energy Efficient Ethernet (EEE) IEEE 802.3az
  • WoL (Wake-on-LAN) support with magic packet detection
  • Programmable power-saving mode
  • IEEE 1588 timestamp start-of-frame detection
  • Diagnostic tools: cable diagnostics, BIST, loopback, fast link-down detection
  • Auto MDI-X in forced mode

Applications

  • - Motor drivers - Factory automation, robotics, and motion control - Grid infrastructure - Building automation - Industrial Ethernet fieldbus - Real-time industrial Ethernet applications, e.g. ProfiNET
