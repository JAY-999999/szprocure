Product Introduction

The TPS562242 is a simple, easy-to-use, high-efficiency, high-power-density synchronous buck converter with an input voltage range of 3V to 17V, supporting up to 2A continuous output current over an output voltage range of 0.8V to 10V.

The TPS562242 uses D-CAP3 control mode to provide fast transient response and supports low-ESR output capacitors with no external compensation required. The device supports up to 94% duty cycle operation.

The TPS562242 operates in Eco-mode to maintain high efficiency at light loads. The device integrates comprehensive hiccup-mode OVP, OCP, UVLO, OTP, and UVP protection.

The device is available in a 1.6mm x 1.6mm SOT-563 package. The rated junction temperature range is -40°C to 125°C.

Features

  • 3V to 17V input voltage range
  • 0.8V to 10V output voltage range
  • 0.8V reference voltage
  • ±1% reference accuracy at 25°C
  • ±1.5% reference accuracy over -40°C to 125°C temperature range
  • Integrated 55.0mΩ and 24.3mΩ MOSFETs
  • 100μA low quiescent current
  • 1.4MHz switching frequency
  • Operation at up to 94% high duty cycle
  • Precision EN threshold voltage
  • 1.6ms fixed soft-start time (typical)
  • Small solution size and easy to use
  • Eco-mode at light load
  • Pin-to-pin compatible with TPS562202
  • D-CAP3 control mode supports startup with pre-biased output
  • Non-latching OV, OT, and UVLO protection
  • Hiccup mode for UV protection
  • Cycle-by-cycle OC protection
