Product Introduction

The HK32C030 is based on the ARM Cortex-M0 core, operating at up to 64 MHz, with up to 64 Kbyte of on-chip Flash (including 61 Kbyte main Flash and a 3 Kbyte Bootloader area configurable as main Flash) and 10 Kbyte SRAM. Interrupt vector remapping within the main Flash area can be achieved by configuring the Flash controller registers. The HK32C030 supports conventional Flash Level 0/1/2 read/write protection. To meet various security application requirements, the HK32C030 provides CRC for verifying the correctness and integrity of data transmission and data storage. The HK32C030 integrates multiple communication interfaces: 3 UART channels (up to 8 Mbit/s) supporting the standard NRZ asynchronous serial data format with full-duplex communication capability. The UART generates various baud rates via its built-in baud rate generator and supports single-wire half-duplex communication, multi-processor communication, and high-speed communication via DMA. 2 high-speed (up to 18 Mbit/s) SPI/I2S channels supporting full-duplex or half-duplex communication with 4~16-bit data length, master/slave mode, TI mode, NSS pulse mode, automatic CRC verification, and I2S protocol. 2 high-speed (up to 1 Mbit/s) I2C channels supporting transfer rates of 1 Mbit/s, 400 kbit/s, and 100 kbit/s, master/slave mode, multi-master mode, 7-bit/10-bit address and SMBus protocol, with data reception wake-up supported in MCU stop mode. The HK32C030 integrates 1 × 16-bit advanced PWM timer (4 PWM output channels, 3 of which feature complementary outputs with dead-time control), 5 × 16-bit and 1 × 32-bit general-purpose PWM timers (up to 4 PWM output channels), and 1 basic timer. The HK32C030 integrates analog circuitry including: 1 × 12-bit ADC (up to 23 analog input channels with differential pair input support; sampling rate up to 1.14 MSPS), 1 × POR/PDR circuit, 1 programmable voltage detector (PVD), and 1 internal reference voltage (sampled via on-chip ADC). The HK32C030 integrates a hardware division and square root unit to enhance software processing capability and accelerate response to external events. All pins of the HK32C030, except power, ground, and NRST, can be used as GPIO, peripheral I/O, or external interrupt inputs, maximizing available signal pins in pin-count-constrained applications. The HK32C030 operates over a temperature range of -40°C to +105°C with a supply voltage of 2.6 V to 5.5 V, meeting the requirements of most application environments.

Features

  • CPU Core:
  • ARM Cortex-M0
  • Maximum clock frequency: 64 MHz
  • 24-bit System Tick timer
  • Interrupt vector remapping supported (configured via Flash controller registers)
  • Main supply VDD operating voltage range: 2.6 V~5.5 V
  • Operating temperature range: -40°C~+105°C
  • Typical operating current — Run mode: 1.46 mA@8 MHz; 7.31 mA@64 MHz
  • Sleep mode: 1.05 mA@8 MHz; 671 μA@32 kHz
  • Stop mode: LDO full speed: 128 μA@3.3 V; LDO low power: 2.8 μA@3.3 V
  • Memory:
  • 64 Kbyte Flash (including 61 Kbyte main Flash region and 3 Kbyte Bootloader region configurable as main Flash)
  • Zero-wait-state bus cycle Flash access supported when CPU frequency ≤ 24 MHz
  • Flash data security protection with independently configurable read and write protection
  • 10 Kbyte SRAM
  • Clock:
  • External high-speed clock (HSE): 4~32 MHz
  • External low-speed clock (LSE): 32.768 kHz
  • Internal high-speed clock (HSI): 8 MHz/16 MHz/64 MHz
  • Internal low-speed clock (LSI): 40 kHz
  • PLL clock: 64 MHz (maximum)
  • GPIO external input clock: 32 MHz (maximum)
  • Reset:
  • External pin reset
  • Option byte loader reset
  • Watchdog (IWDG and WWDG) counter reset
  • Power-on/power-down reset (POR/PDR)
  • Software reset
  • Low-power management reset
  • Programmable Voltage Detector (PVD):
  • 8 selectable detection voltage thresholds
  • Configurable rising-edge and falling-edge detection
  • GPIO Ports:
  • Up to 40 GPIO pins
  • Each GPIO pin configurable as external interrupt input
  • Up to 40 mA drive current
  • Data Communication Interfaces:
  • 3× UART: Configurable baud rates via built-in baud rate generator; supports single-wire half-duplex communication and multi-processor communication
  • 2× High-speed SPI: 4- to 16-bit programmable data frames with multiplexed I2S interface
  • 2× I2C: Ultra-fast mode (1 Mbit/s), SMBus, and PMBus support; wake-up from Stop mode on data reception
  • Timers and PWM Generators:
  • 1× 16-bit advanced timer (TIM1 with 4 PWM outputs, 3 of which include complementary output with dead-time insertion and break function)
  • 5× 16-bit and 1× 32-bit general-purpose timers (TIM2/TIM3/TIM14/TIM15/TIM16/TIM17)
  • 1× 16-bit basic timer (TIM6)
  • DMA controller (5 channels): Supports multiple peripheral triggers including timers, ADC, SPI (I2S), I2C, and UART
  • Fixed-point division/square root unit:
  • 32-bit fixed-point division with simultaneous quotient and remainder output
  • High-precision 32-bit fixed-point square root
  • On-chip analog circuits:
  • 1× 12-bit SAR ADC (up to 23 analog input channels)
  • Maximum conversion rate: 1.14 MSPS
  • Automatic continuous conversion and scan conversion supported
  • Internal reference voltage
  • Temperature sensor: 9-bit resolution, -40°C~+105°C measurement range
  • Calendar RTC with alarm function
  • Data security: CRC hardware unit
  • 96-bit chip UID
  • SWD debug interface
  • ARM CoreSight debug components (ROM Table, DWT, and BPU)
  • Custom DBGMCU debug controller (low-power mode emulation control, debug peripheral clock control, debug and trace interface assignment)
  • Reliability: Qualified to HBM 6500 V / CDM 2000 V / LU 800 mA
