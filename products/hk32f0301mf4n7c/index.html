Product Introduction

The HK32F0301MxxxxC MCU features an ARM Cortex-M0 core with a maximum operating frequency of 48 MHz, 16 KByte built-in Flash, and 4 KByte SRAM. By configuring the Flash controller registers, interrupt vector remapping within the 16 KByte address space can be achieved.

All pins of the HK32F0301MxxxxC, except power and ground, can function as GPIO, peripheral I/O, or external interrupt inputs, providing the maximum possible number of pin signals for pin-constrained applications.

The HK32F0301MxxxxC MCU integrates multiple communication interfaces: 2 high-speed UART channels (up to 6 Mbit/s); 1 high-speed SPI channel (up to 18 Mbit/s) supporting full-duplex/half-duplex communication with 4~16-bit data width, master/slave mode, TI mode, NSS pulse mode, and automatic CRC verification; 1 high-speed I2C channel (up to 400 kbit/s) supporting 100/400 kbit/s transfer rates, master/slave mode, multi-master mode, 7/10-bit addressing, and SMBus protocol. Data reception wakeup is supported in MCU Stop mode.

The HK32F0301MxxxxC MCU integrates one 16-bit advanced PWM timer (4 PWM output channels, 3 of which feature dead-time complementary output), one 16-bit general-purpose PWM timer (4 PWM output channels), and one 16-bit basic timer (timed CPU interrupt output).

The HK32F0301MxxxxC MCU integrates analog circuitry: one 12-bit 1 MSPS ADC, one power-on/power-down reset circuit (POR/PDR/BOR), and one internal voltage reference (sampled on-chip by the ADC).

The HK32F0301MxxxxC MCU supports a wide range of low-power modes. In low-power mode, MCUs in this series can be automatically woken up by the internal low-power timer.

The HK32F0301MxxxxC MCU operates over a temperature range of -40°C to +105°C with a supply voltage of 2.4~5.5 V, meeting the requirements of the vast majority of application environments.

Features

  • CPU Core: ARM Cortex-M0
  • Maximum Clock Frequency: 48MHz
  • 24-bit System Tick Timer
  • Interrupt Vector Remapping Support (configured via Flash controller registers)
  • Operating Voltage Range: 2.4~5.5V
  • Operating Temperature Range: -40°C~+105°C
  • Run Mode: 2.751mA@48MHz@5V
  • Sleep Mode: 0.997mA@48MHz@5V
  • Stop Mode: 373.354μA@5V (LDO normal operation)
  • Low-power Stop Mode: 6.876μA@5V (LDO low-power)
  • 16KByte Flash (64 pages, 256 Byte/page; 32-bit data read, 32-bit data write)
  • Flash data security protection with individually configurable read and write protection
  • 4KByte SRAM
  • CRC hardware unit
  • On-chip High-Speed Internal clock (HSI): 48MHz
  • On-chip Low-Speed Internal clock (LSI): 60kHz
  • GPIO external input clock: 32MHz (maximum)
  • Reset sources: Low level on NRST pin (external reset), Window Watchdog event (WWDG reset), Independent Watchdog event (IWDG reset), Power-on reset, Software reset (SW reset), Low-power management reset
  • GPIO: Up to 18 GPIO ports; each GPIO supports external interrupt input, switchable internal pull-up/pull-down resistors, Open-Drain output, configurable output drive strength
  • IOMUX Pin Multiplexing Controller: For small packages (e.g., SOP8/TSSOP16), enables single-pin mapping to multiple GPIOs or peripheral IOs via IOMUX
  • Data Communication Interfaces: 2× high-speed UART (up to 6Mbit/s), 1× high-speed I2C (up to 400kbit/s, supports data reception wakeup in MCU Stop mode), 1× high-speed SPI (up to 18Mbit/s)
  • Timers & PWM Generators: 1× 16-bit advanced PWM timer (4 PWM outputs, 3 with dead-time complementary output), 1× 16-bit general-purpose PWM timer (4 PWM outputs), 1× 16-bit basic timer (CPU interrupt support), 1× Auto-Wakeup Timer (AWUT) for MCU Stop mode operation
  • On-chip Analog Circuits: 1× 12-bit 1MSPS ADC (up to 7 external analog input channels and 2 internal channels, differential pair input support), 1× power-on/power-off reset circuit, 1× brownout reset circuit, 1× internal reference voltage (sampled on-chip by ADC)
  • CPU Trace & Debug: SWD debug interface, ARM CoreSight debug components (ROM-Table, DWT, BPU), custom DBGMCU debug controller (low-power mode emulation control, debug peripheral clock control, debug and trace interface assignment)
  • Device ID: Each HK32F0301MxxxxC chip provides a unique 96-bit ID
  • Reliability: Qualified to HBM 7000V / CDM 2000V / LU 800mA ratings
