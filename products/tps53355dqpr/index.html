Product Introduction

The TPS53355 is a D-CAP™ mode, 30A synchronous buck converter with integrated MOSFETs. It is designed for ease of use, minimal external components, and space-constrained power systems.

The device features 5mΩ/2mΩ integrated MOSFETs, 1% accuracy, 0.6V reference voltage, and an integrated boost switch. Competitive features include: 1.5V to 15V wide conversion input voltage range, minimal external components, D-CAP™ mode control for ultra-fast transient response, automatic skip mode operation, internal soft-start control, selectable frequency, and no compensation required.

The conversion input voltage range is 1.5V to 15V, supply voltage range is 4.5V to 25V, and output voltage range is 0.6V to 5.5V.

The device is available in a 22-pin 6mm×5mm QFN package.

Features

  • Peak efficiency up to 96%
  • Conversion input voltage range: 1.5V to 15V
  • VDD input voltage range: 4.5V to 25V
  • Output voltage range: 0.6V to 5.5V
  • 5V LDO output
  • Integrated power MOSFETs supporting single-rail input with 30A continuous output current
  • Auto-skip Eco-mode for light-load efficiency
  • Shutdown current <10μA
  • D-CAP mode with fast transient response
  • Selectable switching frequency via external resistor, ranging from 250kHz to 1MHz
  • Selectable auto-skip or PWM-only operating mode
  • Built-in 1% 0.6V reference voltage
  • Selectable internal soft-start: 0.7ms, 1.4ms, 2.8ms, and 5.6ms voltage servo
  • Integrated boost switch
  • Pre-bias startup capability
  • Adjustable overcurrent limit with thermal compensation
  • Overvoltage, undervoltage, UVLO, and overtemperature protection
  • Full ceramic output capacitor support
  • Open-drain power-good indicator
  • Incorporates NexFET power block technology
  • 22-pin QFN package with PowerPAD
  • "Green" option available (RoHS compliant)
