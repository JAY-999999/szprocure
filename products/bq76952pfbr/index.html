Product Introduction

The BQ76952 is a highly integrated, high-precision battery monitor and protector for 3-series to 16-series lithium-ion, lithium polymer, and LiFePO4 battery packs. The device includes a high-precision monitoring system and a highly configurable protection subsystem, with support for autonomous or host-controlled cell balancing. It integrates a high-side charge pump NFET driver, dual programmable LDOs for external system use, and a host communication peripheral supporting 400kHz I2C, SPI, and HDQ single-wire standards. The BQ76952 is available in a 48-pin TQFP package.

Features

  • Battery monitoring for 3 to 16 series-connected cells
  • Integrated charge pump for high-side NFET protection with optional auto-recovery
  • Comprehensive protection suite including voltage, temperature, current, and internal diagnostics
  • Two independent ADCs
  • Synchronous current and voltage sampling
  • High-accuracy coulomb counter with input offset voltage error <1μV (typical)
  • High-accuracy cell voltage measurement <10mV (typical)
  • Wide-range current applications (measurement range of ±200mV across sense resistor)
  • Integrated chemical fuse-driven secondary protection
  • Autonomous or host-controlled cell balancing
  • Multiple power modes (typical battery pack operating range conditions)
  • Normal mode: 286μA
  • Multiple sleep mode options: 24μA to 41μA
  • Multiple deep sleep mode options: 9μA to 10μA
  • Shutdown mode: 1μA
  • High voltage tolerance of 85V on battery connection and select other pins
  • Supports random cell connection sequence during production line
  • Temperature sensing using internal sensor and up to nine external thermistors
  • Integrated one-time programmable (OTP) memory, customer-programmable on production line
  • Communication options include 400kHz I2C, SPI, and HDQ single-wire interface
  • Dual programmable LDOs for external system use
  • 48-pin TQFP package (PFB)

Applications

  • - Battery Backup Unit (BBU) - E-bikes, e-scooters, and LEVs - Cordless power tools and garden tools - Other industrial battery packs (P10S)
