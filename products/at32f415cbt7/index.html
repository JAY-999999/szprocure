Product Introduction

ARTERY AT32F415CBT7 - ARM Cortex-M4 - 150 MHz.

Features

  • 32-bit ARM Cortex-M4 CPU core
  • Up to 150 MHz operating frequency with MPU
  • Single-cycle multiplication and hardware division
  • DSP instruction set
  • 64 KB to 256 KB flash memory
  • 18 KB boot code area for Bootloader
  • sLib: designates a specified main flash region as a secure execute-only code library — code in this region can be called but not read
  • 32 KB SRAM
  • 2.6V ~ 3.6V supply voltage
  • POR, LVR, and PVM
  • Low-power modes: Sleep, Deep Sleep, and Standby
  • VBAT powers LEXT, ERTC, and 20 × 32-bit battery-powered registers (BPR)
  • 4 ~ 25 MHz crystal oscillator (HEXT)
  • Factory-trimmed 48 MHz HICK: ±1% accuracy at 25°C, ±2% accuracy over -40°C ~ +105°C
  • PLL with flexible configuration: 31× to 500× multiplication and 1 to 15 division factors
  • 32 kHz crystal oscillator (LEXT)
  • Low-speed internal clock (LICK)
  • 1 × 12-bit 2 MSPS ADC with up to 16 external input channels
  • Temperature sensor (VTS) and internal reference voltage (VINTRV)
  • 2 × comparators (CMP)
  • 2 × 7-channel DMA controllers, 14 channels total
  • Up to 55 fast GPIO ports
  • All GPIOs mappable to 16 external interrupts (EXINT)
  • Almost all GPIOs 5V-tolerant
  • 1 × 16-bit 7-channel advanced timer: 3 complementary PWM output pairs with dead-time control and emergency stop
  • Up to 5 × 16-bit timers and 2 × 32-bit timers, each with up to 4 channels for input capture/output compare/PWM/pulse counting and incremental encoder input
  • 2 × watchdog timers (general WDT and windowed WWDT)
  • SysTick timer: 24-bit down counter
  • ERTC: enhanced RTC with auto-wakeup, alarm, sub-second precision, hardware calendar, and calibration
  • 2 × I2C interfaces, SMBus/PMBus support
  • 5 × USART interfaces: master synchronous SPI and modem control; ISO7816, LIN, and IrDA
  • 2 × SPI interfaces (36 Mbit/s), both multiplexable as half-duplex I2S
  • CAN interface (2.0B Active) with 256-byte dedicated buffer
  • OTGFS full-speed controller with on-chip PHY and 1280-byte dedicated buffer
  • SDIO interface
  • CRC calculation unit
  • 96-bit unique chip ID (UID)
  • SWD and JTAG interfaces
  • Temperature range: -40°C ~ +105°C

Applications

  • Embedded control
  • IoT devices
  • Industrial automation
  • Consumer electronics
  • Motor control
