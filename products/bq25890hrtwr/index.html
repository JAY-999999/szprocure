Product Introduction

The bq25890H is a highly integrated 5A switch-mode battery charge management and system power path management device for single-cell Li-Ion and Li-Polymer batteries. The device supports high input voltage fast charging. The low impedance power path optimizes switch-mode operational efficiency, reduces battery charge time, and extends battery life during the discharge phase.

The I²C serial interface with charge and system settings makes this device a truly flexible solution. The device supports multiple input sources, including standard USB host ports, USB charging ports, and USB-compatible adjustable high-voltage adapters. Power path management regulates the system voltage to slightly above the battery voltage, but will not drop below the 3.5V minimum system voltage (programmable). The device initiates and completes a charge cycle without software control. The charger provides multiple safety features for battery charging and system operation. The device also provides a 7-bit ADC for monitoring charge current and input/battery/system (VBUS, BAT, SYS, TS) voltages. The QON pin provides BATFET enable/reset control to exit the low-power ship mode or perform a full system reset.

Features

  • High-efficiency 5A 1.5MHz switch-mode buck charging
  • 93% charging efficiency (at 2A charging current) and 91% charging efficiency (at 3A charging current)
  • Optimized for high-voltage input (9V/12V)
  • Low-power PFM mode for light-load operation
  • USB OTG with adjustable output voltage range of 4.5V to 5.5V
  • Selectable 500KHz/1.5MHz boost converter with output current up to 2.4A
  • 93% boost efficiency at 5V/1A output
  • Accurate discontinuous-mode overcurrent protection
  • Battery voltage support down to 2.5V
  • PWM-only or PFM/PWM control for light-load efficiency
  • Single input supporting USB input and adjustable high-voltage adapter
  • Input voltage range: 3.9V to 14V
  • Input current limiting (100mA to 3.25A, 50mA resolution) with USB2.0, USB3.0, and high-voltage adapter support
  • Maximum power tracking via input voltage limiting (up to 14V) for various adapters
  • Auto-detection of USB SDP, CDP, DCP, and non-standard adapters
  • Input Current Optimizer (ICO) for maximizing input power without overloading the adapter
  • IR compensation (IRCOMP) between charger output and battery terminal
  • Maximum battery discharge efficiency via 11mΩ battery discharge MOSFET, discharge current up to 9A
  • ±0.5% charge voltage regulation, ±5% charge current regulation, ±7.5% input current regulation
  • Battery temperature sensing thermal regulation and thermal shutdown for safe operation in charge and boost modes

Applications

  • Smartphones
  • Tablets
  • Portable network devices
