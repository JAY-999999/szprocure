Product Introduction

The N32L40X series adopts a 32-bit ARM Cortex-M4 core with a maximum operating frequency of 64MHz, supporting floating-point operations and DSP instructions. It integrates up to 128KB embedded encrypted Flash, 24KB SRAM, and a rich set of high-performance analog components, including 1 × 12-bit 4.5Msps ADC, 2 independent rail-to-rail op-amps, 2 high-speed comparators, 1 × 1Msps 12-bit DAC, support for up to 24-channel capacitive touch keys, up to 320-segment LCD driver, multiple U(S)ART, I²C, SPI, USB, CAN digital communication interfaces, and a built-in cryptographic algorithm hardware acceleration engine.

Features

  • Core CPU:
  • 32-bit ARM Cortex-M4 core + FPU, single-cycle hardware multiply/divide instructions, DSP instructions and MPU support
  • Built-in 2KB instruction Cache, supports Flash accelerator for zero-wait program execution
  • Up to 64MHz CPU frequency, 80DMIPS
  • Encrypted Memory:
  • Up to 128KByte on-chip Flash with encrypted storage, partition management, data protection, hardware ECC, 100K erase/write cycles, 10-year data retention
  • Up to 24KByte on-chip SRAM, including 16KByte SRAM1 (configurable retention in Stop2 mode) and 8KByte SRAM2 (configurable retention in both Standby and Stop2 modes), hardware parity support
  • Low-Power Management:
  • Standby mode: 1.5uA, all backup registers retained, I/O retained, optional RTC run, 8KByte SRAM2 retention, fast wake-up
  • Stop2 mode: 3uA, RTC run, 8KByte SRAM2 retention, CPU registers retained, I/O retained, fast wake-up
  • RUN mode: 60uA/MHz@64MHz
  • LPRUN mode: PLL off with MSI as system clock, MR off with LRR enabled, USB/CAN/SAC powered down, other peripheral configurations selectable
  • Segment LCD display driver, supports up to 176 segments (4x44) or 320 segments (8x40)
  • High-Performance Analog Interfaces:
  • 1x 12-bit 4.5Msps ADC, multiple configurable resolutions, up to 8Msps in 6-bit mode, up to 16 external single-ended input channels, differential mode support
  • 2x rail-to-rail op-amps with built-in programmable gain amplifier up to 32x
  • 2x high-speed analog comparators with built-in 64-level adjustable reference; COMP1 supports operation in Stop2 low-power mode
  • Up to 24-channel capacitive touch keys, MCU wake-up in low-power state
  • 1x 12-bit DAC, 1Msps sample rate
  • Internal 2.048V independent voltage reference
  • Integrated internal low-voltage detection unit
  • Clocks:
  • 4MHz~32MHz external high-speed crystal, 32.768KHz external low-speed crystal
  • Internal HSI RC: 16MHz
  • Internal MSI RC: 100K~4M
  • Internal LSI RC: 40KHz
  • Built-in high-speed PLL
  • 1x clock output, configurable as low-speed or high-speed clock output
  • Reset:
  • Power-on/power-down/external pin reset
  • Programmable low-voltage detection and reset
  • Watchdog reset
  • Up to 64 GPIOs
  • Communication Interfaces:
  • 5x U(S)ART interfaces: 3x USART (ISO7816, IrDA, LIN support) and 2x UART
  • 1x LPUART, MCU wake-up in Stop2 low-power state
  • 2x SPI interfaces, up to 16Mbps, I²S support
  • 2x I²C interfaces, up to 1MHz, master/slave configurable, dual-address response in slave mode
  • 1x USB2.0 FS Device interface
  • 1x CAN 2.0A/B bus interface
  • 1x high-speed DMA controller, 8 channels per controller, fully configurable source and destination addresses
  • RTC with leap year perpetual calendar, alarm events, periodic wake-up, internal/external clock calibration
  • Timers/Counters:
  • 2x 16-bit advanced timers with input capture, complementary output, quadrature encoder input, up to 9.25nS control resolution; 4 independent channels each, 3 channels support 6x complementary PWM output
  • 5x 16-bit general-purpose timers, 4 independent channels each, input capture/output compare/PWM output
  • 2x 16-bit basic timers
  • 1x 16-bit low-power timer with dual-pulse counting, operable in Stop2 mode
  • 1x 24-bit SysTick
  • 1x 7-bit WWDG
  • 1x 12-bit IWDG
  • Programming:
  • SWD/JTAG in-circuit debug interface
  • UART and USB Bootloader
  • Security Features:
  • Built-in cryptographic hardware acceleration engine supporting AES, DES, TDES, SHA1/224/256, SM1, SM3, SM4, SM7 algorithms
  • Flash encryption, multi-user partition management (MMU)
  • TRNG true random number generator
  • CRC16/32 computation
  • Write protection (WRP), multiple read protection (RDP) levels (L0/L1/L2)
  • Secure boot, encrypted program download, secure update
  • External clock failure detection, tamper detection
  • 96-bit UID and 128-bit UCID
  • Operating Conditions:
  • Supply voltage: 1.8V~3.6V
  • Operating temperature: -40°C~105°C
  • ESD: ±4KV (HBM), ±1KV (CDM)
