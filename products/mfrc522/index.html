Product Introduction

MFRC522 is a widely used contactless card reader IC that integrates multiple contactless communication methods and protocols operating at 13.56 MHz, featuring a high level of technical integration.

Features

  • Reader/writer mode supports ISO/IEC 14443A
  • Reader/writer mode supports ISO/IEC 14443B
  • Highly integrated analog demodulation and decoding circuitry
  • Minimal external components required for output driver connection to antenna
  • Supported host interfaces: I2C (fast mode up to 400k, high-speed mode up to 3400k); UART (up to 1228.8k); SPI (up to 10Mbit/s)
  • 64-byte FIFO buffer for Rx and Tx
  • Flexible interrupt modes
  • Low-power hardware power-down mode
  • Software power-down mode support
  • RC523 supports LPCD function
  • Programmable timer
  • Internal oscillator with 27.12MHz crystal
  • 2.5V–4.0V wide supply voltage range
  • CRC coprocessor
  • Programmable I/O pins
  • Internal self-test function

Applications

  • - Attendance check-in - Access control - Public transportation - Cafeteria dining - Utility recharge (water/electricity/gas) - Portable handheld devices - Various membership systems
