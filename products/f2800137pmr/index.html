Product Introduction

TMS320F280013x (F280013x) is a scalable, ultra-low latency device in the C2000™ real-time microcontroller series, designed to improve the efficiency of power electronics.

Real-time control subsystem is based on TI's 32-bit C28x DSP core, which can provide 120MHz signal processing performance for floating-point or fixed-point code running from on-chip flash or SRAM. The trigonometric function accelerator (TMU) further enhances the performance of the C28x CPU, thereby accelerating the speed of common algorithms critical to real-time control systems.

F280013x supports up to 256KB (128KW) of flash memory. Up to 36KB (18KW) of on-chip SRAM can also be used to supplement the flash memory.

High-performance analog blocks are integrated in the F280013x real-time microcontroller (MCU) and are tightly coupled with the processing unit and PWM unit, thereby providing excellent real-time signal chain performance. 14 PWM channels can control various power stages from three-phase inverters to power factor correction, as well as other advanced multi-level power topologies.

Various industry-standard communication ports (such as SPI, SCI, I2C, and CAN) not only support connectivity but also provide multiple pin multiplexing options for excellent signal layout.
