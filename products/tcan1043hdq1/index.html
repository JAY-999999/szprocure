Product Introduction

The TCAN1043xx-Q1 meets the physical layer requirements of the ISO 11898–2 (2016) high-speed Controller Area Network (CAN) specification, providing an interface between the CAN bus and the CAN protocol controller. These devices support both traditional CAN and CAN FD protocols, with a maximum data rate of 2Mbps. Devices with part numbers ending in "G" are designed for CAN FD applications with data rates up to 5Mbps. The TCAN1043xx-Q1 can selectively enable various power supplies that may be present on the node (via the INH output pin), thereby reducing battery current consumption at the overall system level. This allows power to be delivered to all system components except the TCAN1043xx-Q1 in the ultra-low current sleep state, while the TCAN1043xx-Q1 remains in a low-power state and monitors the CAN bus.

  • AEC Q100 qualified: meets automotive application requirements
  • Temperature Grade 1: -55°C to 125°C, TA device HBM classification level: ±16kV, device CDM classification level: ±1500V
  • Functional Safety capable
  • Documentation available to support functional safety system design
  • Compliant with ISO 11898-2 (2016)
  • All devices support Classic CAN and 2Mbps CAN FD (Flexible Data Rate); "G" option supports 5Mbps
  • Short, symmetrical propagation delay times and fast loop times for increased timing margin
  • Higher data rates on loaded CAN networks
  • VIO level shifting supports 2.8V to 5.5V voltage range
  • Operating modes:
  • Normal mode
  • Standby mode with INH output and local/remote wake-up request
  • Low-power Sleep mode with INH output and local/remote wake-up request
  • Ideal passive behavior when unpowered: high impedance on bus and logic terminals (no load on operating bus or application)
  • Hot-plug capable: power-on/power-off glitch-free operation on bus and RXD output
  • Meets or exceeds EMC standards:
  • Compliant with IEC 62228-3 – 2007
  • Compliant with SAE J2962-2
  • Protection features:
  • IEC ESD protection on bus terminals: ±8kV
  • Bus fault protection: ±58V (non-H versions) and ±70V (H versions)
  • Supply terminal undervoltage protection
  • Driver dominant timeout (TXD DTO): data rates down to 9.2kbps
  • Thermal shutdown protection (TSD)
  • Receiver common-mode input voltage: ±30V
  • Typical loop delay: 110ns
  • Junction temperature range: -55°C to 150°C
  • Available in SOIC (14) and leadless VSON (14) packages (4.5mm×3.0mm) with enhanced AOI capability
