Product Introduction

Analog Devices AD7606BSTZ-RL - SPI - 3.77 V

Features

  • 8/6/4-channel simultaneous sampling input
  • True bipolar analog input range: ±10V, ±5V
  • 5V single analog supply, VDRIVE: 2.3V to 5V
  • Fully integrated data acquisition solution
  • Analog input overvoltage protection
  • Input buffer with 1MΩ analog input impedance
  • 2nd-order anti-aliasing analog filter
  • On-chip precision reference and buffer
  • 16-bit, 200kSPS ADC (all channels)
  • Oversampling via digital filter
  • Flexible parallel/serial interface SPI/QSPI™/MICROWIRE™/DSP compatible
  • Analog input channels with 7kV ESD rating
  • 95.5 dB SNR, -107 dB THD
  • ±0.5 LSB INL, ±0.5 LSB DNL
  • Low power: 100 mW
  • Standby mode: 25 mW
  • 64-pin LQFP package

Applications

  • - Power line monitoring and protection systems - Multi-phase motor control - Instrumentation and control systems - Multi-axis positioning systems - Data acquisition systems (DAS)
