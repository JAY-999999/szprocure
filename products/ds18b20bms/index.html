Product Introduction

The DS18B20B digital thermometer provides 9-bit to 12-bit resolution temperature measurements, with user-programmable nonvolatile memory for setting upper and lower temperature alarm thresholds. The device communicates via a 1-Wire protocol, requiring only a single signal line and a ground line. Its temperature measurement range is -55°C to +125°C (-67°F to +257°F), with a measurement accuracy of ±0.4°C over the -10°C to +70°C range. In addition, it can operate in parasite power mode, drawing power directly from the signal line without requiring an external supply. Each DS18B20B has a unique 64-bit serial number, allowing multiple devices to be daisy-chained on the same 1-Wire bus, with a single microprocessor capable of controlling numerous sensors distributed across a large area. This networking capability is particularly well-suited for HVAC environmental controls, building and equipment temperature monitoring, grain storage monitoring, industrial temperature measurement, and process control applications.

Features

  • Single-wire interface — only one port pin required for communication
  • Globally unique 64-bit serial number per device
  • Multi-point distributed temperature sensing, no external components required
  • Powered via data line; supply voltage range: 2.5V ~ 5.5V
  • Temperature measurement range: -55℃ ~ +125℃ (-67°F to +257°F)
  • Accuracy ±0.4℃ over -10℃ ~ +70℃ range
  • Selectable 9-bit to 12-bit temperature resolution
  • Temperature conversion time < 750ms at maximum 12-bit resolution
  • User-programmable nonvolatile temperature alarm settings
  • Alarm search command identifies and flags devices exceeding set temperature limits
  • High ESD protection: HBM 8000V, MM 800V
  • Available in SMT MSOP8, SOP8 packages and 3-pin TO-92, TO-92S packages

Applications

  • - Temperature control - Industrial systems - Consumer products - Grain temperature monitoring - Thermometers - Any heat-sensing system
