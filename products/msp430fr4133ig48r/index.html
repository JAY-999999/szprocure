Product Introduction

The MSP430FR41xx Ultra-Low Power (ULP) microcontroller series supports low-cost LCD applications, such as remote controls, thermostats, smart meters, blood glucose monitors, and blood pressure monitors. The integrated 10-bit ADC of the devices in this series greatly helps improve the performance of these applications. The MCU features a powerful 16-bit RISC CPU, 16-bit registers, and a constant generator, which contribute to achieving maximum coding efficiency. The Digitally Controlled Oscillator (DCO) enables the device to wake up from a low-power mode to an active mode in less than 10 μs. This architecture, combined with various low-power modes, is the optimal choice for extending the battery life of portable measurement applications. The MSP430 microcontroller platform combines unique embedded Ferroelectric Random Access Memory (FRAM) with a comprehensive ultra-low-power system architecture, enabling system designers to improve performance while reducing energy consumption. FRAM technology combines the low-power, fast write, flexibility, and durability of RAM with the non-volatility of flash memory. The MSP430FR41x MCU is supported by an ecosystem consisting of various software and hardware resources, and reference designs and code examples are provided to help you quickly start your design. Development kits for the MSP430FR41xx include the MSP-EXP430FR4133 LaunchPad development kit and the MSP-TS430PM64D 64-pin target development board. Free MSP430Ware software is also available, which is provided as a component of the desktop and cloud versions of the Code Composer Studio IDE (located in the TI Resource Explorer). A wide range of online supporting materials (such as the Housekeeping Example Series and MSP Academy training) are provided for the MSP430 MCU, and online support is also available through the TI E2E Support Forum.

Features

  • Embedded microcontroller
  • 16-bit RISC architecture up to 16MHz
  • Wide supply voltage range: 1.8V to 3.6V
  • Optimized low-power modes (3V)
  • Active mode: 126μA/MHz
  • Standby mode: <1μA with RTC counter and LCD active
  • Shutdown (LPM4.5): 15nA
  • High-performance analog
  • 10-channel 10-bit ADC
  • 1.5V internal reference voltage
  • Sample-and-hold at 200ksps
  • Supports up to 4×36 or 8×32 segment LCD configurations
  • On-chip charge pump keeps LCD active in standby mode (LPM3.5)
  • Each LCD pin software-configurable as SEG or COM
  • Contrast control from 2.6V to 3.5V (step size 0.06V)
  • Low-power FRAM
  • Up to 15.5KB non-volatile memory
  • Built-in ECC
  • Configurable write protection
  • Unified memory for program, constants, and storage
  • Write endurance up to 10^15 cycles
  • Radiation-tolerant and non-magnetic
  • Intelligent digital peripherals
  • Infrared modulation logic
  • Two 16-bit timers, each with 3 capture/compare registers (Timer_A3)
  • One 16-bit RTC counter (counter-only mode)
  • 16-bit CRC
  • Enhanced serial communication
  • eUSCI_A: UART, IrDA, and SPI
  • eUSCI_B: SPI and I2C
  • Clock System (CS)
  • On-chip 32kHz RC oscillator (REFO)
  • On-chip 16MHz DCO with FLL
  • ±1% accuracy at room temperature (with on-chip reference)
  • On-chip ultra-low-frequency 10kHz oscillator (VLO)
  • On-chip high-frequency modulation oscillator clock (MODCLK)
  • External 32kHz crystal (XT1)
  • Programmable MCLK prescaler (1 to 128)
  • SMCLK derived from MCLK via programmable prescaler (1, 2, 4, or 8)
  • GPIO and pin functions
  • 60 I/Os (64-pin package)
  • 16 interrupt pins (P1 and P2) capable of waking MCU from LPM
  • All I/Os support capacitive touch
  • Development tools and software
  • Development kits (MSP-EXP430FR4133 LaunchPad Development Kit and MSP-TS430PM64D Target Development Board)
  • Free software (MSP430Ware software)
