Product Introduction

This device is a 2Gb, 4Gb, or 8Gb NAND flash memory operating from a 3V supply with an asynchronous interface. It provides hardware and software write protection, and includes an auto-preload feature that loads the first page of data into the internal data register at power-up. The device uses industry-standard NAND interface pins and supports a command-based user interface. Its architecture is organized as 2,112 bytes per page (2,048 bytes plus 64 spare bytes), with 64 pages per block (128K bytes plus 4K bytes). The 2Gb device contains 2,048 blocks in total; the 4Gb device contains 4,096 blocks; and the 8Gb device contains 8,192 blocks. The spare area is typically used to store ECC codes, bad block information, and/or other application-specific metadata. The device is available in a 48-pin TSOP Type 1 package.

Features

  • Organization:
  • Page size:
  • x8: 2,112 bytes (2,048 + 64 bytes)
  • x16: 1,056 words (1,024 + 32 words)
  • Block size: 64 pages (128K + 4K bytes)
  • Device size: 2Gb: 2,048 blocks; 4Gb: 4,096 blocks; 8Gb: 8,192 blocks
  • Read performance:
  • Random read: 25μs
  • Sequential read: 30ns (3V x8 only)
  • Write performance:
  • Page program: 300μs (TYP)
  • Block erase: 2ms (TYP)
  • Endurance: 100,000 PROGRAM/ERASE cycles
  • Data retention: 10 years
  • First block (block address 00h) guaranteed to be valid without ECC (up to 1,000 PROGRAM/ERASE cycles)
  • VCC: 2.7V - 3.6V
  • Automated PROGRAM and ERASE
  • Basic NAND command set:
  • PAGE READ, RANDOM DATA READ, READ ID, READ STATUS, PROGRAM PAGE, RANDOM DATA INPUT, PROGRAM PAGE CACHE MODE, INTERNAL DATA MOVE, INTERNAL DATA MOVE with RANDOM DATA INPUT, BLOCK ERASE, RESET
  • New commands:
  • PAGE READ CACHE MODE
  • READ UNIQUE ID (contact factory)
  • READ ID2 (contact factory)
  • Operation status byte provides a software method of detecting:
  • PROGRAM/ERASE operation completion
  • PROGRAM/ERASE pass/fail condition
  • Write- protect status
  • Ready/busy# (R/B#) pin provides a hardware method of detecting PROGRAM or ERASE cycle completion
  • PRE pin: prefetch on power up
  • WP# pin: hardware write protect
