Product Introduction

ESP32-WROOM-32U and ESP32-WROOM-32D are general-purpose Wi-Fi + Bluetooth + BLE MCU modules that are powerful and versatile, suitable for low-power sensor networks as well as demanding applications such as voice encoding, audio streaming, and MP3 decoding. At the core of both modules is the ESP32-D0WD chip, which is scalable and adaptive. The two CPU cores can be controlled independently. The clock frequency is adjustable from 80 MHz to 240 MHz. Users can power down the CPU and use the low-power co-processor to continuously monitor peripheral status changes or whether certain analog values exceed a threshold. The chip also integrates a rich set of peripherals, including capacitive touch sensors, SD card interface, Ethernet interface, high-speed SDIO or SPI, UART, I2S, and I2C. The module integrates classic Bluetooth, BLE, and Wi-Fi, enabling a wide range of applications: Wi-Fi supports broad-range connectivity and direct Internet access through a router, while Bluetooth allows users to connect to mobile phones or broadcast BLE beacons for signal detection. The chip's sleep current is less than 5 μA, making it suitable for battery-powered wearable electronics. The module supports data transfer rates of up to 150 Mbps, with an antenna output power of 20 dBm for maximum wireless range. The module delivers excellent performance in terms of integration, wireless range, power consumption, and network connectivity. Its operating system is an RTOS with a lightweight IP stack, and it features built-in TLS 1.2 with hardware acceleration. The chip also supports OTA encrypted upgrades, enabling users to continue updating their products after release.

Features

  • Core: ESP32-DOWD chip, ESP32 series, scalable and adaptive
  • Dual CPU cores with independent control, clock frequency adjustable from 80MHz to 240MHz
  • CPU power cut-off supported; low-power coprocessor available for peripheral state monitoring or analog sensing
  • Rich peripherals including capacitive touch sensors, SD card interface, and Ethernet interface
  • Integrated classic Bluetooth, BLE, and Wi-Fi
  • Sleep current below 5μA
  • Data transfer rate up to 150Mbps, antenna output power 20dBm
  • OS: FreeRTOS with LwIP, built-in TLS 1.2 with hardware acceleration
  • OTA encrypted upgrade support

Applications

  • - Low-power sensor networks - Voice coding - Audio streaming - MP3 decoding - Battery-powered wearable electronics
