Product Introduction

TPS63810 and TPS63811 are fully programmable (via I²C), high-efficiency, high-output-current buck/boost converters. Depending on the input voltage, they automatically operate in boost, buck, or a novel 4-switch buck/boost mode when the input voltage is approximately equal to the output voltage.

Mode transitions occur within defined thresholds to prevent unnecessary intra-mode switching, thereby reducing output voltage ripple.

Two output voltage registers accessible via I²C are used to set the output voltage, and the VSEL pin selects which output voltage register is active. This enables the devices to support dynamic voltage scaling. If an output voltage register is changed or the VSEL pin is toggled during operation, the device transitions operating modes at a defined programmable slew rate.

Features

  • Input voltage range: 2.2V to 5.5V
  • Output voltage range: 1.8V to 5.2V
  • I²C configurable during operation and shutdown
  • VSEL pin for switching between two preset output voltages
  • Up to 2.5A when V₁ ≥ 2.5V, V₀ = 3.3V
  • Up to 2.5A when V₁ ≥ 2.8V, V₀ = 3.5V
  • High efficiency across the full load range
  • 13μA low quiescent operating current
  • Automatic power-save mode and forced PWM mode (I²C configurable)
  • Peak current buck-boost mode architecture
  • Configurable transitions between buck, buck-boost, and boost operating modes
  • Forward and reverse current operation
  • Startup into pre-biased output
  • Integrated soft-start
  • Overtemperature and overvoltage protection
  • True load disconnect during shutdown
  • Forward and reverse current limiting
  • TPS63810: Pre-programmed output voltages (3.3V, 3.45V)
  • TPS63811: Programmable output voltage prior to startup
  • Solution size less than 20mm² with only four external components

Applications

  • - System pre-regulator (smartphones, tablets, tracking and telematics, EPOS, TWS earbuds, medical hearing aids) - Point-of-load regulation (time-of-flight camera sensors, port/cable adapters and dongles) - Thermoelectric device power supply (TEC, fiber optic modules) - Broadband network radio or SoC power supply (IoT, home automation, EPOS)
