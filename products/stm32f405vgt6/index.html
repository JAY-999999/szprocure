Product Introduction

This product is a microcontroller based on an ARM 32-bit Cortex-M4 CPU, featuring multiple memory configurations, interface functions, and low-power characteristics.

Features

  • Core: ARM 32-bit Cortex-M4 CPU with FPU, ART Accelerator for zero-wait-state execution from Flash, up to 168MHz, MPU, 210 DMIPS/1.25 DMIPS/MHz (Dhrystone 2.1), DSP instructions
  • Memory: Up to 1MB Flash, up to 192+4KB SRAM (including 64KB CCM data RAM), flexible static memory controller supporting Compact Flash, SRAM, PSRAM, NOR and NAND memory
  • LCD Interface: 8080/6800 mode parallel interface
  • Clock & Power Management: 1.8V to 3.6V application supply and I/Os; POR, PDR, PVD, BOR support; 4 to 26MHz crystal oscillator; internal 16MHz factory-trimmed RC (1% accuracy); 32kHz RTC oscillator with calibration; internal 32kHz RC with calibration
  • Low-Power Modes: Sleep, Stop, Standby modes; VBAT supply for RTC, 20×32-bit backup registers + optional 4KB backup SRAM
  • Analog: 3×12-bit ADCs (2.4 MSPS, up to 24 channels, triple interleaved mode 7.2 MSPS); 2×12-bit DACs
  • DMA: 16-stream general-purpose DMA controller with FIFO and burst support
  • Timers: Up to 17 timers (up to 12×16-bit, 2×32-bit, up to 168MHz), up to 4 IC/OC/PWM or pulse counters each, quadrature encoder input support
  • Debug: Serial Wire Debug (SWD) and JTAG; Cortex-M4 Embedded Trace Macrocell
  • Packages: LQFP64 (10×10mm), LQFP100 (14×14mm), LQFP144 (20×20mm), LQFP176 (24×24mm), WLCSP90, UFBGA176 (10×10mm)
  • I/O: Up to 140 with interrupt capability; up to 136 fast I/Os (up to 84MHz); up to 138 5V-tolerant I/Os
  • Communication Interfaces: Up to 15, including 3×I2C (SMBus/PMBus), 4×USART/2×UART (10.5 Mbit/s, ISO7816, LIN, IrDA, modem control), 3×SPI (42 Mbit/s, 2 with multiplexed full-duplex I2S), 2×CAN (2.0B Active), SDIO
  • Advanced Connectivity: USB 2.0 full-speed device/host/OTG controller (on-chip PHY); USB 2.0 high-speed/full-speed device/host/OTG controller (dedicated DMA, on-chip full-speed PHY and ULPI); 10/100 Ethernet MAC (dedicated DMA, IEEE 1588v2 hardware support, MII/RMII)
  • Additional Features: 8-14-bit parallel camera interface (up to 54MB/s); true random number generator; CRC calculation unit; 96-bit unique ID; sub-second accuracy RTC (hardware calendar)
