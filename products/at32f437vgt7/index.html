Product Introduction

32-bit Cortex-M4 MCU + FPU with 256 KB to 4032 KB internal flash, sLib, dual QSPI, SDRAM, dual OTGFS, Ethernet, camera interface, 18 timers, 3 ADCs, 23 communication interfaces

Features

  • Core: 32-bit Cortex-M4 with FPU
  • CPU up to 288 MHz operating frequency, with Memory Protection Unit (MPU), single-cycle multiplication and hardware division
  • Built-in Floating Point Unit (FPU)
  • DSP instruction set
  • 256 KB to 4032 KB internal Flash memory
  • sLib: designates a specified main Flash region as a secure execution-only library; code in this region can be called but not read
  • Default 384 KB SRAM, configurable up to 512 KB
  • External Memory Controller (XMC) with 16-bit data bus: supports CF card, SRAM, PSRAM, NOR, NAND, and SDRAM
  • Up to 2 QSPI interfaces for external SPI Flash or SPI RAM expansion, supporting memory-mapped mode
  • XMC as LCD parallel interface, compatible with 8080/6800 modes
  • 2.6 to 3.6 V supply voltage
  • Power-On Reset (POR), Low-Voltage Reset (LVR), Power Voltage Monitor (PVM)
  • Low-power modes: Sleep, Deep Sleep, and Standby
  • VBAT powers LEXT, ERTC, and 20 × 32-bit battery-powered registers (BPR)
  • 4 to 25 MHz crystal oscillator (HEXT)
  • Built-in factory-trimmed 48 MHz High-speed Internal Clock (HICK): ±1% accuracy at 25°C, ±2.5% accuracy over -40 to +105°C, with Auto Clock Calibration (ACC)
  • PLL with flexible multiplier and divider configuration
  • 32 kHz crystal oscillator (LEXT)
  • Low-speed Internal Clock (LICK)
  • 3 × 12-bit 5.33 MSPS ADCs, up to 24 external input channels; selectable resolution of 12/10/8/6 bits; hardware oversampling up to 16-bit resolution
  • Temperature sensor (VTS), internal reference voltage (VINTRV), VBAT battery voltage monitoring (VBAT/4)
  • 2 × 12-bit DACs
  • 2 general-purpose DMA controllers and 1 enhanced EDMA controller, 22 channels total
  • Up to 116 fast GPIO ports
  • All GPIOs mappable to 16 external interrupts (EXINT)
  • Nearly all GPIOs 5 V input tolerant
  • Up to 18 timers (TMR)
  • Up to 13 × 16-bit and 2 × 32-bit timers, each with up to 4 channels for input capture/output compare/PWM/pulse counting
  • 2 watchdog timers (general WDT and window WWDT)
  • SysTick timer: 24-bit down counter
  • ERTC: enhanced RTC with auto-wakeup, alarm, sub-second precision, hardware calendar, and calibration
  • Up to 23 communication interfaces
  • Up to 3 I2C interfaces, supporting SMBus/PMBus
  • Up to 4 USART / 4 UART interfaces, supporting ISO7816, LIN, IrDA, modem control, and RS485 driver enable; configurable TX/RX pin swap
  • Up to 4 SPI interfaces (36 Mbit/s), all 4 usable as I2S; I2S2/I2S3 support full-duplex
  • Up to 2 CAN interfaces (2.0B Active)
  • Up to 2 OTG full-speed controllers, Crystal-less operation supported in device mode
  • Up to 2 SDIO interfaces
  • Infrared transmitter (IRTMR)
  • 10/100M Ethernet MAC (EMAC): dedicated DMA and 4 KB SRAM, IEEE 1588 support, MII/RMII interface (AT32F437 only)
