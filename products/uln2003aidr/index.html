Product Introduction

The ULx200xA devices are high-voltage, high-current Darlington transistor arrays. Each device consists of seven NPN Darlington pairs featuring high-voltage outputs with common-cathode clamp diodes for switching inductive loads.

The collector current rating for a single Darlington pair is 500mA. Darlington pairs can be connected in parallel to achieve higher currents.

The ULN2002A device is specifically designed for 14V to 25V PMOS devices. Each input of this device includes a series Zener diode and resistor to keep the input current within a safe range. Each Darlington pair in the ULx2003A device features a 2.7kΩ series base resistor for direct compatibility with TTL or 5V CMOS devices.

The ULx2004A device features a 10.5kΩ series base resistor, enabling direct operation from CMOS devices using supply voltages of 6V to 15V. The ULx2004A device requires lower input current than the ULx2003A device and lower input voltage than the ULN2002A device.

Features

  • 500mA rated collector current (single output)
  • High voltage output: 50V
  • Output clamp diode
  • Compatible with various logic inputs

Applications

  • - Relay drivers - Stepper and brushed DC motor drivers - Lamp drivers - Display drivers (LED and gas discharge elements) - Line drivers - Logic buffers
