Product Introduction

This 4-bit non-inverting translator uses two separate configurable power-supply rails. Port A is designed to track VCCA. VCCA accepts any supply voltage from 0.9V to 3.6V. Port B is designed to track VCCB. VCCB accepts any supply voltage from 0.9V to 3.6V. This allows any low-voltage bidirectional translation between the 1V, 1.2V, 1.5V, 1.8V, 2.5V, and 3V voltage nodes. For the TXB0304, when the output enable (OE) input is low, all outputs are in the high-impedance state. To ensure the high-impedance state during power-up or power-down, OE should be connected to GND through a pulldown resistor; the minimum value of this resistor depends on the current-sourcing capability of the driver. The OE device-control pin input circuit is powered by VCCA. This device is fully suitable for partial power-down applications using I0ff. The I0ff circuit disables the outputs to prevent damaging backflow current when the device is powered down. The only difference between the TXB0304 and TXBN0304 is that the OE signal is active high and active low, respectively.

Features

  • Fully symmetrical supply voltage, 0.9V to 3.6V on both Port A and Port B
  • VCC isolation feature – if either VCC input is grounded, all outputs are in high-impedance state
  • Output enable (OE) input referenced to VCCA
  • Low power consumption, 5μA maximum (ICCA or ICCB)
  • Ioff supports partial power-down mode operation
  • Latch-up performance exceeds 100mA (compliant with JESD 78 Class II specifications)
  • ESD protection exceeds JESD 22 specifications – 8000V Human Body Model (A114-A), 1000V Charged Device Model (C101)
