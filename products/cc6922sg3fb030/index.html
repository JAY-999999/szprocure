Product Introduction

CC6922 is a high-performance Hall-effect current sensor capable of measuring DC or AC current with high accuracy, excellent linearity, and good temperature stability, widely used in industrial, consumer, and communication equipment.

The CC6922 integrates a high-precision, low-noise linear Hall circuit and a low-impedance primary current conductor. The ultra-low 0.3mΩ conductor resistance minimizes power loss and heat dissipation. The inherent internal isolation provides 5000VRMS galvanic isolation between the input current path and the secondary circuit. The sensor employs linear Hall sensor temperature compensation technology for superior temperature stability.

The differential common-mode rejection circuit integrated in the CC6922 prevents the output from being affected by external interference magnetic signals; the integrated dynamic offset cancellation circuit ensures the sensitivity is unaffected by external mechanical stress and package stress.

Another key feature of the CC6922 is its open-drain fast fault monitoring function, making it ideal for overcurrent fault detection. This feature offers flexible application in fault detection and greatly simplifies PCB layout. The reference voltage (VREF) supports differential measurements and sets the reference voltage (VOC) for the overcurrent fault threshold.

The CC6922 is available in an SOP16W package, operates over a temperature range of -40 to +125°C, and complies with RoHS requirements.

Features

  • Built-in VREF output and external VREF input dual reference modes
  • In built-in VREF output mode, VOE programmable to <5mV
  • In external VREF input mode, VOUT quiescent output voltage tracks external VREF
  • Wide measurement range: multiple full-scale options of 20A, 30A, 40A, 50A, 65A, 75A, 80A, 100A, 125A, 150A
  • User-configurable overcurrent threshold VOC with low-latency fault flag output xFAULT
  • Low noise, single-ended analog output
  • High isolation voltage: 5000VRMS safety isolation between conductor pins and signal pins
  • 1500VRMS basic insulation, 750VRMS reinforced insulation
  • Low loss, conductor resistance 0.3mΩ
  • High bandwidth up to 250kHz, step response time 1.2µs
  • Room temperature error 1%, sensitivity temperature drift ±2.5%
  • Excellent temperature stability with Hall signal amplification and temperature compensation circuitry
  • Differential Hall structure for strong immunity to external magnetic interference
  • High mechanical stress resistance, magnetic parameters unaffected by external pressure
  • ESD (HBM) 4kV, ESD (CDM) 2kV, LU 500mA

Applications

  • Motor control
  • Load monitoring systems
  • Switching power supplies
  • Overcurrent fault protection
  • OBC
  • Photovoltaic inverters
