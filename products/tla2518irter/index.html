Product Introduction

The TLA2518 is an easy-to-use 8-channel multiplexed 12-bit 1MSPS successive approximation register analog-to-digital converter (SAR ADC). The 8 channels can be independently configured as analog inputs, digital inputs, or digital outputs. The device features an internal oscillator for performing the ADC conversion process. The TLA2518 communicates via an SPI-compatible interface and supports averaging multiple data samples through single conversion initiation. The built-in programmable averaging filter helps reduce noise from the analog inputs and decreases the number of data samples the host needs to read.

Features

  • Compact package: WQFN 3mm × 3mm
  • 8-channel, configurable in any combination: up to 8 analog inputs, digital inputs, or digital outputs
  • GPIO for I/O expansion: open-drain, push-pull digital outputs
  • Wide operating range: AVDD: 2.35V to 5.5V, DVDD: 1.65V to 5.5V, temperature range: -40°C to +85°C
  • Enhanced SPI digital interface: high-speed 60MHz interface, maximum throughput with >13.5MHz SPI
  • Programmable averaging filter: programmable sample size for averaging, averaging via internal conversions, 16-bit resolution

Applications

  • - Macro Remote Radio Unit (RRU) - Battery Management System (BMS) - String Inverter - Central Inverter
