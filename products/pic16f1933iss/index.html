Product Introduction

PIC 8 Bit 32MHz SSOP-28-208mil Microcontrollers RoHS

Features

  • High-precision internal oscillator:
  • Factory-calibrated to ±1% (typical)
  • Software-selectable frequency range: 31 kHz to 32 MHz
  • Power-saving Sleep mode
  • Power-on Reset (POR)
  • Power-up Timer (PWRT) and Oscillator Start-up Timer (OST)
  • Brown-out Reset (BOR):
  • Selectable between 2 trip points
  • Optionally disabled in Sleep mode
  • Master Reset multiplexed with pull-up/input pin
  • Programmable code protection
  • Wide operating voltage range:
  • 1.8V - 5.5V (PIC16F1933)
  • 1.8V - 3.6V (PIC16LF1933)
  • Standby current:
  • Typical 60 nA at 1.8V
  • Operating current:
  • Typical 75 μA/MHz at 1.8V
  • Timer1 oscillator current:
  • Typical 600 nA at 32 kHz, 1.8V
  • Low-power WDT current:
  • Typical 500 nA at 1.8V
  • Up to 35 I/O pins and 1 input-only pin:
  • High source/sink current for direct LED drive
  • Individual programmable interrupt-on-change pins
  • Individual programmable weak pull-ups
  • Integrated LCD controller:
  • Up to 96 segments
  • Variable clock input
  • Contrast control
  • Internal reference voltage selection
  • Capacitive sensing module (mTouch™):
  • Up to 16 selectable channels
  • A/D converter:
  • 10-bit resolution with up to 14 channels
  • Selectable 1.024/2.048/4.096V reference voltage
  • Timer0: 8-bit timer/counter with 8-bit programmable prescaler
  • Enhanced Timer1:
  • Dedicated low-power 32 kHz oscillator driver
  • 16-bit timer/counter with prescaler
  • External gate input mode (with toggle and single-event modes)
  • Interrupt on gate event completion
  • Timer2, 4, and 6: 8-bit timer/counter with 8-bit period register, prescaler, and postscaler
  • 2 Capture/Compare/PWM (CCP) modules:
  • 16-bit capture, maximum resolution 125 ns
  • 16-bit compare, maximum resolution 125 ns
  • 10-bit PWM, maximum frequency 31.25 kHz
  • 3 Enhanced Capture/Compare/PWM (ECCP) modules:
  • 3 PWM timebase options
  • Auto-shutdown and auto-restart
  • PWM steering control
  • Programmable dead-band delay
  • Master Synchronous Serial Port (MSSP) supporting SPI and I²C:
  • 7-bit address masking
  • SMBus/PMBus™ compatible
  • Auto-wake-up on Start
  • Enhanced Universal Synchronous Asynchronous Receiver Transmitter (EUSART):
  • RS-232, RS-485, and LIN compatible
  • Auto baud rate detection
  • SR Latch (555 timer):
  • Multiple Set/Reset input options
  • 555 timer application emulation
  • 2 comparators:
  • Rail-to-rail input/output
  • Power-mode control
  • Software-selectable hysteresis
  • Voltage reference module:
  • Fixed Voltage Reference (FVR) output levels: 1.024V, 2.048V, and 4.096V
  • 5-bit rail-to-rail resistive DAC with positive and negative reference voltage selection
