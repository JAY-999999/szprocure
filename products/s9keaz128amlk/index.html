Product Introduction

NXP Semiconductors S9KEAZ128AMLK - ARM Cortex-M0+ - 48 MHz - 128 KB Flash - 71 I/O

Features

  • Operating Range:
  • Voltage range: 2.7 to 5.5 V
  • Flash programming voltage range: 2.7 to 5.5 V
  • Temperature range (ambient): -40 to 125°C
  • Performance:
  • ARM Cortex-M0+ core up to 48 MHz
  • Single-cycle 32-bit × 32-bit multiplier
  • Single-cycle I/O access port
  • Oscillator (OSC): Supports 32.768 kHz crystal or 4 MHz to 24 MHz crystal or ceramic resonator; selectable low-power or high-gain oscillator
  • Internal Clock Source (ICS): Composed of internal or external reference clock source and internal FLL; internal 37.5 kHz pre-calibrated reference clock source available for 48 MHz system clock
  • Internal 1 kHz low-power oscillator (LPO)
  • System Peripherals:
  • Power Management Controller (PMC) with three power modes: Run, Wait, and Stop; resettable, interruptible low-voltage detection (LVD) module with selectable trip point
  • Watchdog (WDOG) with independent clock source; configurable CRC module
  • Serial Wire Debug (SWD) interface
  • SRAM bit-band region (BIT-BAND)
  • Bit Manipulation Engine (BME)
  • Security and Integrity Module: 80-bit unique ID per device
  • Human-Machine Interface:
  • Up to 71 GPIO
  • Two 32-bit keyboard interrupt (KBI) modules
  • External interrupt (IRQ) module
  • Analog Modules:
  • One 12-bit SAR ADC with up to 16 channels, operable in Stop mode, with selectable hardware trigger source (ADC)
  • Two analog comparators (ACMP) with 6-bit DAC and configurable reference input
  • Timers:
  • One 6-channel FlexTimer/PWM (FTM)
  • Two 2-channel FlexTimer/PWM (FTM)
  • One 2-channel periodic interrupt timer (PIT)
  • One pulse width timer (PWT)
  • One real-time clock (RTC)
  • Communication Interfaces:
  • Two SPI modules (SPI)
  • Up to three UART modules (UART)
  • Two I²C modules (I²C)
  • One MSCAN module (MSCAN)
  • Package Options:
  • 80-pin LQFP
  • 64-pin LQFP
