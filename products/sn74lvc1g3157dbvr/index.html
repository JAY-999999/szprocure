Product Introduction

This single-pole, double-throw (SPDT) analog switch is designed for 1.65-V to 5.5–VCC operation.

The SN74LVC1G3157 can handle both analog and digital signals. The device permits signals with amplitudes of up to VCC (peak) to be transmitted in either direction.

Features

  • Operating voltage range: 1.65V to 5.5V
  • Break-before-make switching
  • Rail-to-rail signal handling
  • High linearity
  • Fast switching speed, typical 0.5 ns (VCC=3 V, CL=50 pF)
  • Low on-state resistance, typical ≈6 Ω (VCC=4.5 V)
  • Latch-up performance exceeds 100 mA, compliant with JESD 78 Class II
  • ESD protection exceeds JESD 22: HBM 2000-V (A114-A), MM 200-V (A115-A), CDM 1000-V (C101)
  • Absolute maximum ratings: supply voltage range -0.5 V to 6.5 V, control input voltage range -0.5 V to 6.5 V, switch I/O voltage range -0.5 V to VCC+0.5 V (max 5.5 V), control input clamp current -50 mA, I/O port diode current ±50 mA, on-state switch current ±128 mA, VCC or GND continuous current ±100 mA
  • Package thermal resistance: DBV package 165°C/W, DCK package 259°C/W, YEP/YZP package 123°C/W
  • Storage temperature range: -65°C to 150°C
  • Unused inputs must be tied to VCC or GND for proper device operation
  • Available packages: DBV, DCK, YEP, YZP

Applications

  • - signal gating - chopping - modulation or demodulation (modem) - signal multiplexing for analog-to-digital and digital-to-analog conversion systems
