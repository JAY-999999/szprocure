Product Introduction

The N32WB03x series Bluetooth chips are a new generation of high-performance, ultra-low-power Bluetooth 5.1 chips. Built on a 32-bit ARM Cortex-M0 core with a maximum operating frequency of 64MHz, they integrate 48KB SRAM and 256/512KB Flash on-chip.

The integrated advanced BLE 5.1 RF transceiver complies with the Bluetooth BLE 5.1 specification and is configurable for standard 1Mbps BLE mode, 2Mbps enhanced BLE mode, 125kbps BLE long-range mode (S8), and 500kbps BLE long-range mode (S2). In BLE 1M or 2M mode, it supports AOA (Angle of Arrival) and AOD (Angle of Departure), RSSI, master/slave roles, multi-connection, data length extension, KEYSCAN, IRC, 10-bit 1.33Msps ADC (configurable to 16-bit 16Ksps), analog MIC input with PGA amplification, basic/general/advanced TIMERs, RTC, WWDG, IWDG, LPUART, USART, SPI, I2C, and other peripherals.

Suitable for a wide range of applications including Bluetooth keys, OBUs, data transmission modules, Bluetooth voice remote controls, and smart home devices.

Features

  • Core CPU: 32-bit ARM Cortex-M0, up to 64MHz
  • Memory: 256K/512K bytes Flash, 48K bytes SRAM
  • RF Specifications:
  • BLE 1Mbps RX sensitivity: -96dBm
  • BLE 2Mbps RX sensitivity: -93dBm
  • Programmable TX power, up to +6dBm
  • Single-ended antenna port
  • Clock:
  • HSE: 32MHz external high-speed crystal
  • LSE: 32.768KHz external low-speed crystal
  • HSI: Internal high-speed RC 64MHz
  • LSI: Internal low-speed RC 32KHz
  • 1 clock output, configurable for different clock sources, output after divide-by-4
  • Reset:
  • Power-on/power-off and external pin reset
  • Watchdog reset
  • Communication Interfaces:
  • 2× USART, up to 4Mbps (configurable as ISO7816, IrDA, LIN)
  • 1× LPUART with low-power features, up to 9600bps in Sleep mode, supports low-power wakeup
  • 2× SPI, up to 16MHz, master/slave configurable, configurable as I2S
  • 1× I2C, up to 1MHz, master/slave configurable
  • Timers/Counters:
  • 1× 16-bit advanced timer: input capture, output compare, PWM output, quadrature encoder input; 4 independent channels, 3 of which support 6-channel complementary PWM output
  • 1× 16-bit general-purpose timer: input capture, output compare, PWM output, one-pulse output; 4 independent channels
  • 1× 16-bit basic timer
  • 1× 24-bit SysTick timer
  • 1× 7-bit WWDG
  • 1× 12-bit IWDG
  • Analog Interfaces:
  • 1× 10-bit 1.33Msps ADC (configurable as 16-bit 16Ksps), 5 external single-ended channels, 1 differential MIC channel, 2 internal channels
  • Built-in PGA, up to 128× gain
  • MIC BIAS voltage: 1.6V–2.3V adjustable
  • 21 GPIO with multiplexed functions
  • 1× high-speed 5-channel DMA controller
  • 1× IR transmit controller, configurable IR remote control protocol
  • 1× KEYSCAN module, 8/10/13 GPIOs configurable as 44/65/104 key functions
  • RTC with leap year perpetual calendar, alarm event, periodic wakeup
  • Hardware CRC16 and CRC32
  • Operating Conditions:
  • Supply voltage: 1.8V/2.32V ~ 3.6V
  • Operating temperature: -40℃ ~ 85℃
  • ESD: ±2KV (HBM)
  • Package: QFN32 (4mm×4mm)
