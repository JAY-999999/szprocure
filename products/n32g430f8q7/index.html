Product Introduction

The N32G430 series features a 32-bit ARM Cortex-M4F core with a maximum operating frequency of 128MHz, supporting floating-point operations and DSP instructions. It integrates up to 64KB embedded encrypted Flash, 16KB SRAM, and a rich set of high-performance analog components, including a built-in 1× 12-bit 4.7Msps ADC, 3 high-speed comparators, and multiple digital communication interfaces such as U(S)ART, I2C, SPI, and CAN.

Features

  • 32-bit ARM Cortex-M4 core + FPU, supporting DSP instructions and MPU
  • Built-in 1KB instruction Cache, supports Flash accelerator unit for zero-wait program execution
  • Maximum clock frequency 128MHz, 160DMIPS
  • 64KByte on-chip Flash, supports encrypted storage, partition management, 10,000 erase/write cycles, 10-year data retention
  • 16KByte on-chip SRAM, retained in Stop2 mode, configurable retention in Standby mode
  • Supports Run, Sleep, Stop0, Stop2, and Standby modes
  • 1x 12-bit 4.7Msps ADC, configurable as 12/10/8/6 bits, up to 16 external single-ended input channels, 3 internal single-ended input channels, supports differential mode
  • 3 high-speed comparators with built-in 64-level adjustable reference voltage
  • HSE: 4MHz~32MHz external high-speed crystal
  • LSE: 32.768KHz external low-speed crystal
  • HSI: internal high-speed RC 8MHz
  • LSI: internal low-speed RC 40KHz
  • Built-in high-speed PLL
  • MCO: supports 2 clock outputs, configurable as SYSCLK, HSI, HSE, LSI, LSE, or dividable PLL clock output
  • Supports power-on/power-off/external pin reset
  • Supports watchdog reset and software reset
  • Supports programmable voltage detection
  • Up to 39 + 1 GPIOs
  • 4x U(S)ART interfaces: 2x USART (supports 1x ISO7816, 1x IrDA, LIN), 2x UART
  • 2x SPI interfaces, master mode up to 18Mbps, slave mode up to 32Mbps, supports I2S communication
  • 2x I2C interfaces, up to 1MHz, configurable master/slave mode, dual-address response in slave mode
  • 1x CAN 2.0A/B bus interface, up to 1Mbps
  • 1x high-speed DMA controller, 8 channels, freely configurable source and destination addresses
  • RTC with leap year perpetual calendar, alarm events, periodic wake-up, supports internal/external clock calibration
  • 1x Beeper, supports complementary output, 12mA output drive capability
  • 2x 16-bit advanced timer/counters, supporting input capture, complementary output, and quadrature encoder input, maximum control resolution 7.8ns; each timer has 4 independent channels — Timer1 supports 4 channels with 8 complementary PWM outputs, Timer8 supports 3 channels with 6 complementary PWM outputs
  • 4x 16-bit general-purpose timer/counters, each with 4 independent channels, supporting input capture/output compare/PWM output
  • 1x 16-bit basic timer/counter
  • 1x 16-bit low-power timer/counter, supports dual-pulse counting, operable in STOP2 mode
  • 1x 24-bit SysTick
  • 1x 14-bit window watchdog (WWDG)
  • 1x 12-bit independent watchdog (IWDG)
  • Supports SWD/JTAG debug interface
  • Supports UART Bootloader
  • Flash storage encryption, multi-user partition management (MMU), CRC16/32 computation
  • Supports write protection (WRP), multiple read protection (RDP) levels (L0/L1/L2)
  • Supports secure boot, encrypted program download, and secure update
  • Supports external clock failure detection and tamper detection
  • 96-bit UID and 128-bit UCID
  • Operating voltage range: 2.4V~3.6V
  • Operating temperature range: -40℃~105℃
  • ESD: ±4KV (HBM model), ±2KV (CDM model)
  • Packages: LQFP32 (7mm x 7mm), LQFP48 (7mm x 7mm), QFN20 (3mm x 3mm), QFN28 (4mm x 4mm), QFN32 (4mm x 4mm), QFN48 (6mm x 6mm), TSSOP20 (6.5mm x 4.4mm), TSSOP20-1 (6.5mm x 4.4mm)
